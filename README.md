# 图像分类四任务项目：深度学习模型设计与实验分析
**—— 从植物物种到人脸表情：数据画像、模型结构、单变量实验与选型论证**

## 📖 项目简介
本项目为机器学习/深度学习课程设计。围绕视觉领域的分类、定位与分割问题，按递进关系设计了四个独立任务。每个任务统一按照“数据画像 → 模型结构 → 训练过程 → 单变量实验 → 模型选择”的标准化协议展开，并在报告中详细记录了消融实验矩阵、训练异常追踪以及最终选型论证。

项目全部代码在 Kaggle 平台完成开发与训练。

## 🧠 核心任务详解

### 第1章：五类植物物种分类（Plant Seedlings）
- **难点**：小样本（500张）、类间相似性极高、高度离散的图像分辨率。
- **实验**：设计了23组单变量实验（覆盖数据增强、解冻策略、优化器调度等）。
- **结论**：随机尺寸裁剪是唯一稳定有效的增强，解冻到layer4性价比最高，余弦退火与权重衰减带来稳定收益；而提高分辨率、颜色抖动、随机旋转均无正向作用。
- **异常记录**：完整记录了“标签映射错位”与“验证/测试预处理不一致”两次事故的排查过程，并给出解决方案。

### 第2章：人脸表情分类（Emotion Classification）
- **数据特性**：48×48 单通道灰度、类别不均衡（2.25:1）、标注主观。
- **结论**：本任务瓶颈是欠拟合。性能增量的 84% 来自换用预训练骨干（ResNet18 → ConvNeXt-T），有效策略是更强骨干与更长训练，而非正则化或后处理。

### 第3章：眼底图像中心凹定位（Fovea Localization）
- **难点**：极小样本（训练80张/测试20张），需处理“中心凹不可见时取(0,0)”的情形。
- **方案**：对比了两阶段（检测+ROI回归）与单阶段（热图回归）。最终采用热图回归 + 坏标注清洗 + 15模型 trimmed median 融合，确保了本地 OOF 误差与公开成绩的极高一致性。

### 第4章：眼底血管分割（Vessel Segmentation）
- **难点**：仅20张训练图。评估链路存在严重错位（任务要求血管像素置0，官方脚本却将>0编码为血管）。
- **结论**：在极小样本任务上，评估链路的正确性优先于模型精度。修正极性并全量投入训练后，使用轻量模型便取得了极佳的公开成绩。

## 💡 核心创新点

1. **量化验证集选择偏差**：将100张验证集的选择偏差量化为 95% 置信区间 ±5~7 个百分点，提出“线上成绩 + 本地线上一致性 + 训练稳定性”三重选型准则，避免“单点最高验证F1”带来的过拟合。
2. **评估链路纠错优先**：针对极小样本分割，用极性错位导致“训练与验证指标割裂”的实例，证明了评估链路正确性的决定性作用。
3. **高一致性模型融合**：在坐标回归任务上采用 trimmed median 跨模型融合，验证了本地 OOF 与公开成绩的高度一致性。
